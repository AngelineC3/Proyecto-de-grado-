# 📥 Bandeja de Entrada (Inbox)

Esta carpeta es para **captura rápida de ideas sin filtrar**:
* Ideas sueltas que surjan durante el día o en clase.
* Apuntes rápidos de reuniones con el docente asesor.
* Dudas para investigar más adelante.

> **Regla de mantenimiento**: Una vez por semana, revisa tu `00-inbox/`, procesa las notas y muévelas a `05-zettelkasten/` o a las secciones correspondientes en `capstone/`.
